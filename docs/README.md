# Documentation map

This directory separates the current operating guidance from retained decisions,
retrospectives, and delivery evidence. A historical record is not execution
authority; follow the task at hand and the repository rules.

## Start here

- [Lean workflows](lean-workflows.md) — current authority, validation,
  delegation, context, Scout, and routing guidance.
- [Delivery workflow](delivery-workflow.md) — outcome-driven delivery
  compatibility guidance and runtime boundary.
- [Execution service](execution-service.md) — shared tmux execution-service
  interface and lifecycle boundary.
- [One-shot transport](one-shot-transport.md) — retained CLI, timeout,
  evidence, cancellation, and fixed-grant details for the default compatibility
  transport; its obsolete mandatory-validator statement is marked superseded.
- [Native code mode](codemode.md) — optional settings and bounded-output use.
- [Addy engineering](addy-engineering.md) — six-phase guidance and its limits.
- [One-pager](one-pager.md) and [progress](progress.md) — separately opt-in
  capabilities.

## Current planning and maintenance

- [Maintenance index](maintenance/README.md) — current repository map,
  historical-status convention, and diagram placeholder.
- [Machinery plan](maintenance/machinery-plan.md) — evidence-gated runtime and
  context proposals; not implementation authority.
- [Workflow and skills plan](maintenance/workflow-skills-plan.md) — practical
  guidance improvements; not implementation authority.
- [Retention inventory](maintenance/retention-inventory.md) — keep/cleanup
  classifications and required gates. Nothing is removed by that inventory.

## Retained records

- `workflows/` contains plans, source-capability records, retrospectives, and
  first-release evidence. Read the status notice in each record before acting.
- `delivery/` contains retained task evidence, snapshots, and handoffs. It is
  evidence, not the current runtime configuration or a cleanup queue.
- [Pi fresh start](pi-fresh-start.md) and [day-one handover](handover-day1.md)
  are historical setup records with their own notices.
- [Lean workflow improvements](lean-workflow-improvements.md) preserves the
  decision history behind the current lean guidance.
