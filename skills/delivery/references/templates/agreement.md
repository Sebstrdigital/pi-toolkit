# Optional authority section

Use in conversation, an existing issue/JSON or task record. No separate file or snapshot directory required. A clear execution request is sufficient; do not ask for a second confirmation.

Work: <outcome, acceptance, exclusions; supporting files included unless explicitly restricted>.
Permissions: <unusual side effects, private data, destructive/outward actions only where authorized>.
Limits: <only explicit user-agreed limits; no invented repair counts or role pools>.
Authority: <actual execution request or approval reference; proposals alone do not authorize execution>.

Ordinary reversible edits, diagnosis, checks, repair and reconciled continuation are included. A consequential new outcome/permission/required-check boundary needs a decision and a short dated note. No default commit/install/destructive cleanup/push/PR/publish authority. Earlier explicit narrow grants remain binding.
